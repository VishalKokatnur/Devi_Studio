# Devi Studio – Photographer Website (React + Vite + Tailwind)

Owner: Vittal Kokatnur · Darga Road, opposite Sai High Tech School, Vijayapura

## Run in VS Code
```bash
npm install
npm run dev      # opens at http://localhost:5173
npm run build    # production build in /dist
```

## Edit content
Everything is in `src/data.js`: phone, Instagram, hours, photos, services, reviews.

Add real photos: copy files into `public/photos/` and set `src: "/photos/01.jpg"` on each photo in `data.js`.
Photos with `hero: 1` appear in the top slideshow. Set `site.profile` for Vittal's portrait.
Sample reviews, "1000+ shoots", "500+ clients" and opening hours are placeholders: confirm with the client.
